Conversational Flow & Interaction Design
Conversational UX Designer · 2024–2026
AI Summary Bot · Multi-template Iterative Dialogue
User Flow
1. START → User sends: YouTube URL / File / Text / Link

2. BOT → detects intent → suggests 3 templates

3. USER selects template → Bot generates structured summary

4. USER refines: «Раскрой Risks» / «Сделай короче» / «Добавь цитаты»

5. BOT regenerates ONLY that section (context preserved)

6. EXPORT: Markdown / JSON / Copy to clipboard
Key Interaction Patterns
  • ✅ Progressive Disclosure — сначала overview, потом детали по запросу
  • ✅ Template Switching — «Переделай в Action Items» → перегенерация
  • ✅ Context Preservation — история диалога + исходный контент
  • ✅ Error Recovery — «Не понял, уточни» → graceful fallback
  • ✅ Rate Limiting — Free tier 3/мес, понятные лимиты

Customer Journey Map + Service Blueprint
CX Lead / Service Designer · 2014–2017 · UHNWI
Жуковка / Сады Майендорф · Premium Real Estate
Context
Продукт: Элитный загородный клуб
Пользователи: UHNWI резиденты
Боль: Не качество услуг, а неопределённость в коммуникациях
Тревога: «Что происходит? Когда закончится? Кто отвечает?»
3 Scenarios (CJM)
Сценарий 1: Плановые работы
Touchpoints: SMS (24ч) → Email (2ч) → Push (старт) → Push (завершение)
Emotions: Спокойствие → Информированность → Уверенность
Pain (до): Неожиданность, нет времени подготовиться
Solution: Триггерные уведомления + Tone of Voice
Сценарий 2: Аварийная ситуация
Touchpoints: SMS (мгновенно) → Звонок → Статус в app → SMS (решение)
Emotions: Тревога → Поддержка → Контроль → Облегчение
Pain (до): Тишина, паника, повторные звонки
Solution: Проактивная коммуникация, SLA 5 мин
Сценарий 3: Бытовой запрос
Touchpoints: Приложение/Чат → Принятие → Статусы → Завершение → Оценка
Emotions: Удобство → Прозрачность → Завершённость
Pain (до): Запрос теряется, нет обратной связи
Solution: Единое окно, трекинг, CSAT
